## Package intent

This package presents the latest OPC system as a coherent document set:
- the `01-core` layer defines general orchestration doctrine
- the `02-creative` layer specializes OPC for creative / production-shaped work
- the `03-meta` layer records convergence status rather than adding new policy

## Notes

- This package is a document-layer export, not the full implementation repo.
- Historical docs elsewhere in the repository may still be valuable, but they are not treated as the main current doctrine for this package.
