# OPC v2 Documentation

This directory contains the latest organized documentation snapshot for the current OPC system.
It is intended to be git-friendly, reviewable, and easier to navigate than a flat reference dump.

## Scope

This documentation package focuses on the current OPC doctrine rather than historical implementation notes.
It covers:
- general OPC orchestration doctrine
- controller / dispatch / review / closeout rules
- creative-production OPC protocol stack
- convergence and normalization status artifacts

## Structure

- `00-index.md` — reading order and quick map
- `01-core/` — general OPC doctrine
- `02-creative/` — creative-production protocol stack
- `03-meta/` — convergence / normalization state

## Intended use

Use this as the document-first version to submit into git when you want a clean narrative of the current OPC system.
It is deliberately separated from older `docs/` materials that may include earlier design stages, demos, or historical notes.
