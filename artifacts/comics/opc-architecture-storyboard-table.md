# OPC 架构知识漫画｜画师版分镜表

## 项目
- 标题：《总指挥室的 8 个舱：一看就懂 OPC》
- 类型：知识漫画 / 架构科普漫画
- 统一隐喻：总指挥室 / 中控调度台 / 独立工作舱
- 视觉主线：复杂任务压境 → CEO 启动 OPC → 中控编排 → 小队独立执行 → 自动回报 → CEO 收口

## 视觉总原则
- CEO 永远处在“思考 / 判断 / 收口”位置，不画成亲自逐项干活
- Control Plane 永远画成系统/台面/塔台，不画成第二个会思考的人
- Child sessions 永远在独立工作舱里，强调独立上下文
- 第 9 个任务必须画成排队，不是失败
- 最终答案只从 CEO 主屏形成，不从 child 直接对外交付

## 重复口号
- 主口号：复杂任务，不靠分身乱冲；靠总指挥室有序编排。
- 页间短句：CEO 思考，Control Plane 调度，Child 专项执行。
- 强化规则版：8 个槽位并行跑，结果回到 CEO 才算数。

## 封面 / 封底文案
- 封面：一个复杂任务压来时，CEO 不亲自逐项奔波，而是通过中控调度台编排最多 8 个独立工作舱并行处理。
- 封底：这就是 OPC：只为复杂、可拆解的任务而生——Child 在独立 session 中执行，自动回报；最终答案，永远由 CEO 汇总形成。
