# OPC 架构知识漫画｜角色与场景锚点包

## 目标

为漫画出图提供统一视觉锚点，保证封面、分页、分格在角色与场景上保持一致。

---

## 1. CEO（总指挥）

### 角色定位
- 主会话的拟人化形象
- 唯一总负责人
- 负责理解任务、拆解任务、做最终汇总

### 视觉关键词
- calm strategist
- futuristic commander
- minimal yet authoritative outfit
- clean silhouette
- not over-decorated
- composed, focused, not frantic

### 外观锚点
- 年轻到中年之间的中性科技感形象
- 深色简洁制服/风衣式外层，带极简发光线条
- 面前始终有总控台与主屏
- 姿态偏“判断、观察、下达指令”，而不是低头埋头执行

### 禁止偏差
- 不画成热血战士
- 不画成夸张军装元帅
- 不画成正在亲手做细碎执行任务的人

---

## 2. Control Plane（中控调度台）

### 角色定位
- 系统基础设施，不是第二主角
- 调度、派发、监控、回收的可视化载体

### 视觉关键词
- control console
- orchestration dashboard
- slot-based scheduler
- status lights
- routing lines
- result return pipelines

### 视觉锚点
- 一个大型弧形/环形中控台
- 台面上明确有 8 个并发槽位
- 有任务卡流转线、状态灯、排队区、回收管道
- 更像“机场塔台 + 数据中控”的融合体

### 禁止偏差
- 不拟人化成会说话的机器人主角
- 不画成和 CEO 同等级的思考者
- 不画得过花哨，必须一眼看出是系统台面

---

## 3. Child Session（独立工作舱小队）

### 角色定位
- 专项执行单元
- 在独立会话里处理单个专项任务

### 视觉关键词
- independent work pod
- isolated context cabin
- specialized operator
- single-purpose execution

### 视觉锚点
- 每个 child 在独立工作舱内
- 舱门编号 1~8
- 每个舱有独立屏幕、资料板、操作台
- 舱与舱之间物理分隔明显
- child 形象不必复杂，重点是“专注、隔离、单线程”

### 禁止偏差
- 不画成多人挤在一个房间里
- 不画成 child 们彼此开会讨论
- 不画成 child 知道全局全貌

---

## 4. 第 9 个任务（排队任务）

### 角色定位
- 并发规则拟人化表达

### 视觉关键词
- queued task
- waiting token
- number 9 card
- not rejected, only queued

### 视觉锚点
- 可拟人化为抱着文件夹的小角色
- 身上或手上有明显 “9” 标记
- 站在 QUEUE / WAITING 区
- 表情应是着急但未被否定

### 禁止偏差
- 不画成失败者
- 不画成被驱逐
- 不画成额外的 child session 正在偷偷运行

---

## 5. 复杂任务风暴

### 角色定位
- 任务压力的外化

### 视觉关键词
- task storm
- information overload cloud
- layered mission pressure
- incoming complex workload

### 视觉锚点
- 像压向玻璃幕墙的巨大乌云/文件浪潮
- 云里飘浮“调研、分析、验证、写作、汇总”等关键词
- 带警报感，但不要末日废土感

---

## 6. 场景锚点：总指挥室

### 视觉关键词
- futuristic command room
- clean sci-fi architecture
- panoramic main screen
- calm high-tech leadership space

### 场景要求
- CEO 居中
- 中控台在前方/侧前方
- 工作舱在后方或侧后方形成阵列
- 主屏可显示结构图、任务卡、结果汇总

### 统一配色
- 主色：蓝灰 / 冷白 / 深石墨
- 警示：红色
- 完成态：青绿或明亮蓝白

---

## 7. 镜头与构图原则

### CEO
- 常用中景、半身、主位构图
- 构图稳定，不夸张扭曲

### Control Plane
- 常用俯视/斜俯视 UI 构图
- 便于表达调度关系和槽位

### Child Pods
- 常用横向并列构图
- 强调并行与隔离

### 收官页
- 全景收束图
- CEO / 中控 / 8 舱必须形成完整闭环视觉

---

## 8. 统一画风建议

- clean futuristic knowledge comic
- cinematic infographic storytelling
- readable panel composition
- semi-realistic sci-fi illustration
- not chibi, not overly cartoonish
- suitable for explaining systems clearly

---

## 结论

这个锚点包的目标不是让角色复杂，而是让系统结构在每一页都稳定可识别。
